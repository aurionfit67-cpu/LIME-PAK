# Quick Start Guide

Get up and running with AI Company Builder in minutes!

## 🎯 What You'll See

When you first open the app, you'll land on the **Dashboard** with:

- ✅ Demo company: **Acme Innovations**
- ✅ CEO and C-suite team members
- ✅ 4 AI agents ready to chat
- ✅ Active projects with tasks
- ✅ Company knowledge base
- ✅ Everything pre-configured and functional

## 🚀 Try These Features

### 1. Chat with AI Agents (5 seconds)

1. Click **"AI Workforce"** → **"Agents"** in the sidebar
2. Click on any agent card (e.g., "Atlas" or "Mercury")
3. Type a message like:
   - "Create a marketing strategy for our Q2 launch"
   - "Analyze our financial performance"
   - "What features should we prioritize?"
4. Watch the AI respond with relevant, role-specific advice!

### 2. Create a New AI Agent (30 seconds)

1. Go to **"AI Workforce"** → **"Agent Builder"**
2. Fill in the form:
   - **Name**: Phoenix
   - **Role**: Sales Strategist
   - **Department**: Sales
   - **Purpose**: Drive revenue growth through strategic sales initiatives
   - **Personality**: Energetic, persuasive, results-driven
3. Select tools like "Data Analysis" and "Email Management"
4. Add permissions
5. Click **"Create Agent"**
6. Your new agent is ready! Go chat with them!

### 3. Generate a Website (10 seconds)

1. Click **"Build"** → **"Website Builder"**
2. Click **"+ New Website"**
3. Enter a prompt like:
   ```
   Create a modern SaaS landing page with a hero section,
   features, testimonials, and a strong call-to-action
   ```
4. Click **"✨ Generate Website"**
5. Wait 2 seconds for AI to generate
6. Click on your new website to preview it
7. Click **"Preview"** to see the full website
8. Click **"Publish"** when ready!

### 4. Manage Projects & Tasks (20 seconds)

1. Go to **"Work"** → **"Tasks"**
2. See the Kanban board with 4 columns:
   - To Do
   - In Progress
   - Review
   - Done
3. **Drag and drop** tasks between columns
4. Watch them update instantly
5. Click on a task to see details
6. See which team members or AI agents are assigned

### 5. Explore Company Structure (10 seconds)

1. Go to **"Company"** → **"Organization"**
2. See the org chart with CEO at the top
3. View all C-suite positions
4. See company mission and vision
5. Understand the team structure

1. **Chat Context**: Each AI agent responds based on their role. Ask Atlas about strategy, ask Sage about finances!
